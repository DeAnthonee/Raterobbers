# Eye Spy

A fast, top-down, grid-based online heist game for the web. Teams of burglars race through a mansion of hand-built rooms, search furniture for hidden gems, and hold the most when the timer runs out.

**Start here:** [docs/GAME_SPEC.md](docs/GAME_SPEC.md) — the product/game spec, architecture, and milestones.

> This repository previously held an Android mini-game. It is being repurposed for the game above; the Android project is removed in milestone M0 and remains available in git history.
